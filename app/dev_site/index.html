LOCAL PARSER PLAYGROUND

Four fixtures.
One article parser.

Check metadata extraction and lesson-image selection using small, synthetic article pages. Everything is served from this repository.

How to use this lab

Open a fixture to compare the visible article with the real parser's metadata and selected image. The two error cases deliberately have no usable lesson image.

Images, styles and HTML are local files. Chosun-shaped source URLs and example.test image URLs in the extracted data are synthetic identifiers and are never requested. This site does not run OCR, save records or call the manual scrape endpoint. That endpoint continues to reject localhost URLs.

Enabled explicitly with ENABLE_TEST_SITE=true. Keep it unset or false on deployed services.
